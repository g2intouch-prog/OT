📖 User Guide & Help Center

🔍
Disconnected from Server (Working Offline)

This application is engineered with an offline-first architecture to ensure you can log data under any network condition.

  • Status Ring: The circular ? button in the top-right corner represents your network status. A green glow indicates active online connection. A red glow indicates you are disconnected.
  • Offline Drafts: When disconnected (red glow), you can still enter records. Clicking "Save Draft" logs them securely to local storage.
  • Synchronizing: When connection is restored (green glow), your local drafts will display at the bottom of the Data Entry page. Select the records and click "Push Selected" to sync them to the database.

The core panel lets you fill out logging forms and save them as drafts.

  • Next Row (Save): Pressing Enter or clicking "Save Draft (Next Row)" saves the current values and focuses on the first field for the next entry.
  • Voice Dictation: Click the microphone 🎤 icon next to any input or the main microphone button to dictate inputs using speech recognition.
  • Keyboard Navigation: Use Tab to cycle fields and Enter to save drafts.

Admins can dynamically alter the shape of the data entry form to suit changing logging needs.

  • Field Types: Define fields as Text, Number, Date, Time, Dropdown menus, or Checkboxes.
  • Validation: Mark crucial columns as "Required" or enforce specific boundaries (e.g. min/max numbers).
  • Save Schema: Changes made here must be saved to the server. Note: This will dynamically update the forms for all client machines immediately.

Ingest bulk datasets from existing spreadsheets easily.

  • File Upload: Drag & drop or select your .xlsx, .xls, or .csv spreadsheet.
  • Column Mapping: Map columns in your spreadsheet to the corresponding target fields in your active form schema.
  • Preview & Import: Preview rows for alignment, handle validation checks, and commit them to drafts.

Browse, inspect, and verify synchronized records in the central vault.

  • Filter & Search: Narrow down logs by month/year using the dropdown filters.
  • Verification: Review unverified records and click Verify (requires admin authorization) to sign them off.
  • Corrections: Admins can edit or delete committed records. Deleted records go to the sync console trash bin where they can be restored or purged.

Configure credentials and set up multi-factor security overlays.

  • 2FA (TOTP): Set up Google Authenticator or similar tools under Settings. Scan the QR code, then confirm with the code to activate.
  • Local Backups: Export a JSON backup file of all offline drafts to avoid loss in case of browser database wipe, or restore from a previously exported backup file.

🛡️ Administrator (Full Access)

  • Team Management: Invite new team members via email & assign roles (Admin, Operator, Viewer).
  • Master Email: Update Master email under Settings → Master Admin Account.
  • Purge Accounts: Click Purge Old Users to delete old logins while preserving your active Master Admin account.
  • Approve Password Resets: Review pending password reset requests under Settings → My Team → 🔔 Password Reset Requests. Click Approve & Reset to generate a temporary password for the user.
  • Form Customization & Auditing: Full control over Form Creator, verifying logs, record edits, and database backups.

📝 Data Entry Operator

  • Data Logging & Voice Input: Access to Data Entry form, microphone voice typing, draft saving, and offline sync.
  • Password Change: Click the 🔑 key icon beside your name in the top-left sidebar menu at any time to change your password.
  • Forgot Password Request: Click Forgot Password? on the login window to send a reset request directly to your Administrator.

📊 Viewer

  • Read-Only Reports: Browse, filter, search, print, and export reports & analytics.
  • Password Change: Change your password at any time via the 🔑 key icon in the top-left sidebar menu.
  • Forgot Password Request: Submit password reset requests to the Administrator via the Forgot Password? link on the login window.

Specialized workflow for logging multi-foetal deliveries (Twins, Triplets) without skewing OT surgery counts.

  • 1 Surgery = 1 OT Sl. No.: Selecting Twins, Triplets, or Quadruplets under Pregnancy Type spawns dynamic sub-cards for each infant (Gender, Time of Birth, Weight, Apgar). All infants are saved inside 1 surgery record so your OT surgery count remains 100% accurate.
  • Multi-Foetal Analytics: Track total multi-foetal surgeries, twin/triplet ratios, and infant birth statistics on the compact Analytics Dashboard.

🔑 Data Decryption Recovery Tool

If database records fail to decrypt after a password change or key rotation, enter your previous account password below. The system will derive the matching decryption key, recover all undecrypted records, and auto-heal your database with your current active vault key.
